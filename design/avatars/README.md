## How the parts fit together

Each SVG has a 240 × 240 viewBox and three groups:

- `#bg`: the rhythm's colour and its sky detail (sun, moon or stars).
- `#animal`: the rhythm's animal, kept inside x 20–165.
- `#prop`: the habit's prop, kept inside the slot around x 140–215, y 80–205.

To make any of the 36 types, combine one background, one animal and one prop.

Everything stays inside the circle, so the art can be cropped round as a profile picture. It uses only the app's
palette: blush beige, lavender, butter, mint, olive, coral, periwinkle, ink #1C1917 and orange #C2410C as an
accent. There is no text in the art and nothing human.
